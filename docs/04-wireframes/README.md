Design Notes

- All screens will use a consistent sidebar navigation.
- The dashboard will display important farm information.
- Tables will organize farm records clearly.
- Forms will allow users to add and update information.
- Buttons will be easy to identify and use.

These wireframes serve as the initial layout guide for the final web application.
