Smart Poultry Care Management System

1. Project Overview

The Smart Poultry Care Management System is a web-based application designed to help poultry farm owners manage and monitor their daily farm activities. It organizes important information such as farm details, flock records, feeding schedules, vaccinations, egg production, expenses, and reminders.

The main goal of this system is to reduce manual record keeping, improve data organization, and make farm management easier and more efficient.

2. Users and What They Need to Do

| User Role | What They Need to Do |
|---|---|
| Farm Owner | Manage farm information, monitor flock records, check egg production, and view expenses. |
| Farm Staff | Record feeding schedules, update vaccination records, and enter daily egg production. |
| Administrator | Manage system records and maintain the accuracy of information. |

3. The Database Behind It

Database Name: `smart_poultry`

Number of Tables: 8

| Table | Description |
|---|---|
| FARM | Stores farm information and owner details. |
| FLOCK | Stores poultry flock information, breed, and population. |
| FEED_TYPE | Stores available feed types and their costs. |
| FEEDING_SCHEDULE | Records feeding dates, times, and quantities. |
| VACCINATION | Stores vaccination records and next due dates. |
| EGG_PRODUCTION | Records daily collected and damaged eggs. |
| EXPENSE | Stores farm expenses and descriptions. |
| REMINDER | Stores feeding, vaccination, and other reminders. |

4. Must-Have Features

1. Add, edit, delete, and view farm information using the FARM table.
2. Add and manage poultry flock records using the FLOCK table.
3. Add and search available feed types using the FEED_TYPE table.
4. Create and update feeding schedules using the FEEDING_SCHEDULE table.
5. Record and monitor vaccinations using the VACCINATION table.
6. Record daily egg production using the EGG_PRODUCTION table.
7. Add and track farm expenses using the EXPENSE table.
8. Create and update farm reminders using the REMINDER table.

5. Nice-to-Have Features

1. Display a dashboard showing total flocks and egg production.
2. Generate monthly farm expense reports.
3. Show notifications for upcoming vaccination schedules.
