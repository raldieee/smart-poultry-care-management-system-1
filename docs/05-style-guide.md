Style Guide – Smart Poultry Care Management System

1. Color Palette

The system uses green and white colors to represent nature, poultry farming, and cleanliness.

| Color | Hex Code | Usage |
|---|---|---|
| Primary Green | #2E7D32 | Main buttons and navigation |
| Dark Green | #1B5E20 | Headings and hover effects |
| Light Green | #E8F5E9 | Background highlights |
| White | #FFFFFF | Main background |
| Dark Gray | #333333 | Main text |
| Light Gray | #F5F5F5 | Cards and sections |
| Red | #D32F2F | Delete buttons and warnings |

2. Typography

- Primary Font: Poppins
- Secondary Font: Arial
- Headings: Bold
- Body Text: Regular
- Buttons: Medium or Bold

3. Buttons

| Button | Color | Purpose |
|---|---|---|
| Add | Green | Add new records |
| Edit | Blue | Update existing records |
| Delete | Red | Remove records |
| Save | Dark Green | Save information |
| Cancel | Gray | Cancel an action |

4. Form Design

- Use clear labels for every input field.
- Use white input backgrounds.
- Add rounded corners to input fields.
- Provide clear validation messages.
- Use green buttons for saving records.

5. Navigation Design

The system will use a left sidebar navigation containing:

- Dashboard
- Farm Management
- Flock Management
- Feed Management
- Feeding Schedule
- Vaccination Records
- Egg Production
- Expense Management
- Reminders

6. Layout and Spacing

- Use a consistent sidebar on every page.
- Keep enough spacing between sections.
- Use cards to display important information.
- Use tables to organize records.
- Make the design responsive for desktop and mobile devices.

7. Overall Design Concept

The Smart Poultry Care Management System will have a clean, modern, and user-friendly design. Green will be the main color, supported by white and light gray backgrounds. The layout will help farm owners easily manage poultry records and daily farm activities.
